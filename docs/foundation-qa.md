# Fixed-pipeline acceptance conditions

This review defines current correctness and evidence obligations. It does not report executed checks or certify a commit. [Quality](quality.md), [build](build.md) and [document-quality evaluation](document-quality.md) own the detailed verification requirements.

| Boundary | Required healthy and negative controls |
| --- | --- |
| Admission | Closed binary/continuous plans, before-I/O UTF-8/path/value validation, moved-request refusal, and impossible binary photometric/protection state. |
| Lifecycle | Actual-entry ordering, immutable preparation, partial observations, known identity decisions, direct-owner failures, delegated upstream errors, and untouched later stages. Prepared illumination may precede later identity or refusal; other incomplete predecessors prohibit later entry. |
| Numerical facts | Shared family validators reject contradictory flags, impossible counts/ranges, fake settled effects and unrequested failures. Zero evaluated illumination samples require neutral application gain extrema. Legitimate failed solver diagnostics remain available. |
| Ownership | Live/unmoved borrow owners, inactive moved models, PSF/report moves, payload/refund accounting, finite native reservations and foreign exception containment. |
| Publication/delivery | Exclusive commit, monotone known publication, unknown fallback without late allocation, checked stream flush and no execution/delivery retry. |
| Geometry | Independent asymmetric samples, all supported orientations/turns, B-frame masks, F-frame PSFs and unequal-density transpose parity. |
| Contracts | Actual executable catalog, sole method-argument attribution, independent response/record versions, exact generation, obsolete-form refusal and complete record/response agreement. |
| Build/security | Immutable source/feature/tool identity, source/compiler/linter coverage, native closure and hardening/import/notice inspection, both strict engines, retained regressions, ASan/UBSan and TSan. |
| Platform qualification | Exact-commit seven-lane coverage, physical minimum OS/CPU checks and relocated package execution. Missing, failed, skipped or cancelled evidence cannot qualify. |
| Quality evidence | Frozen corpus/settings/build/panel/assignment, independently identified receipt, distinct original/replay identities, bounded raw response interpretation, exact protected integer samples and full semantic agreement. |
| Human claims | Rights/provenance review, independent physical pages, blind human review, complete per-class denominators and separate harms/uncertainty/abstention. Synthetic controls never establish natural-document benefit. |

Source/package identity hashes establish byte binding, not trust, authenticity, clearance or chronology. A workflow definition, PR, local pass or synthetic fixture cannot substitute for the exact execution or human evidence it describes. Merge and release eligibility require their own complete latest-commit evidence and explicit authorization.
